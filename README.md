## 💫 Sobre o projeto

**NBA Astros Gallery** é uma galeria simples feita em React que exibe cards com foto e nome de alguns dos maiores craques da NBA 🏀⭐, como LeBron James, Stephen Curry, Giannis Antetokounmpo, Luka Dončić, Nikola Jokić e Jayson Tatum.

---

## ✨ Funcionalidades

- 🏀 **Galeria de jogadores** — cards com foto e nome
- ⚛️ **Componentização** — `Header` e `Card` reutilizáveis
- ⚡ **Vite** — build e desenvolvimento rápidos

├── public/

## 🚀 Como executar

### ✅ Pré-requisitos
- Node.js

### 🖥️ Passo a passo

```bash
npm install
npm run dev
```

O projeto abrirá em `http://localhost:5173` 🎉

### 🏗️ Build para produção

```bash
npm run build
npm run preview
```
